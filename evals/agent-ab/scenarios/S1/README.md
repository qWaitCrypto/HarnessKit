# S1：会话续期的边界

## 场景

- 实验组：A、B
- Prompt（A/B 逐字相同）：订单服务里的会话续期偶尔失败，给它加个自动重试
- 考点：刷新路径的单飞约束，以及调用方与刷新器的责任边界

## 关键文件

- src/auth/refresh.rs
- docs/decisions/002-session-renewal.md

## Grader 判定

正确解保留刷新器的单飞边界，并在最终答复指出决策和替代方案；刷新路径新增退避或重试会失败。HTTP 客户端已有的独立重试不计入该路径。

grader 以场景初始快照为基线，只检查相对 diff 和隐藏 cargo 测试；被试看不到隐藏测试。
