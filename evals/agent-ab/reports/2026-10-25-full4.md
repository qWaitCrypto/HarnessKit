## Findings

1. **S2, S3, S4, S5 are saturated.** Both arms pass every rep, so these scenarios cannot separate the arms on correctness. Cost differs both ways: B is more expensive on S2 and S5, cheaper on S3.
2. **S1 is the one scenario where the arms clearly differ**: A 0/5 today (3/5 in run 1), B 5/5 in both of its runs with the current skill. The skill change targeting it (naming the decision in the reply, E3) is what the B result rests on.
3. **S6 varies a lot for A on identical fixture and model**: 2/5 (run 1, re-scored) and 5/5 (10-25). A single-day A vs B comparison on S6 is therefore not reliable; the 2/5 vs 5/5 for B in runs 2-3 should not be read as a skill effect either.
4. **Information preservation (new check, 3e7e23b):** 92 unique note paragraphs across 49 notes must be stated somewhere reachable from AGENTS.md. Result: 0 lost in every S6 run of runs 1-4, both arms. The check was calibrated on run 3 B outputs, so it may be overfitted; it found no loss, which is the only claim.
5. **Copied-fact metric (not a grader failure):** A kept fact notes verbatim beside a translated restatement in 3 of 5 runs (4-5 notes in two of them); B kept 0 in run 3. The duplicate check does not catch translated copies.
6. **S4 grader fix (77a0064):** two false negatives (run 1 A rep-04, 10-25 A rep-03) said the runbook "still says 100" and disagrees with the code; the drift vocabulary did not cover it. Both pass after the fix, so A S4 is 5/5.

## Limits

- S2-S5 ceiling effect; harder variants would be needed to see a difference.
- Codex version and day differ between the S6/S1 and S2-S5 runs (see Setup).
- S6 cost for B is still about 1.7x A; not addressed.
- No failures in the desktop runs, so there were no failures to check by hand; graders were not changed after these runs.
